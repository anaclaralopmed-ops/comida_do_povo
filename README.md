# Comida do Povo — HTML + CSS

Arquivos:
- index.html — tela inicial
- cardapio.html — cardápio
- cadastro.html — cadastro do cliente
- autor.html — sobre o autor
- style.css — estilos de todas as telas

## Como testar
Abra `index.html` no navegador.

## GitHub Pages
Envie todos os arquivos para o mesmo repositório. Depois, em Settings → Pages, selecione a branch principal e a pasta `/root`.

Observação: as fotos do cardápio usam URLs do Unsplash para reproduzir visualmente o protótipo. Para um projeto 100% independente, substitua essas URLs por imagens salvas em uma pasta `img/`.
